# Debug Coach

Leer werken met Claude op je eigen werk. Zeven missies, elk met een echt resultaat voor jouw job, en een coach die uitlegt wat Claude doet en waarom, tot je hem niet meer nodig hebt.

## Installeren

In de Claude desktop-app, in Cowork:

```
/plugin marketplace add BinaryBjorn/debug-coach
```

en installeer daarna de plugin `debug-coach`.

## Starten

1. Open Cowork en kies een lege map in je OneDrive als werkmap.
2. Typ `/start`.
3. Claude zet je werkmap klaar en leert jou kennen: dat is missie 1.

## Wat er in je werkmap komt

| Bestand | Waarvoor |
|---|---|
| `CLAUDE.md` | Het projectbrein: wat Claude elke keer eerst leest over jou en over hoe de coach werkt |
| `ik/profiel.md` | Wie je bent: rol, dossiers, werkwijze, stijl |
| `voortgang.md` | Waar je staat in de zeven missies |
| `feedback.md` | Na elke missie twee korte vragen. Dit bestand deel je met Bjorn, nooit inhoud uit je werk |
| `successen.md` | Wat werkte: de vraag en het resultaat, om later te hergebruiken |
| `projecten/` | Je projecten per onderwerp (missie 2) |

## Updates ophalen

Claude ververst een plugin niet vanzelf.

1. `/plugin marketplace update debug-marketing`
2. Typ `/plugin`, open `debug-coach` en kies bijwerken.
3. Open een nieuw venster. Pas dan werkt de nieuwe versie.
